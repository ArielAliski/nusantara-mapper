# Base geometry sources

`units.geojson` and `land.geojson` are generated by `npm run base` (scripts/build-base.mjs).
They are simplified derivatives of the following datasets.

| Data | Source | License |
|---|---|---|
| Indonesian regencies and cities (ADM2) | Badan Pusat Statistik (BPS), WFP and OCHA ROAP, via [geoBoundaries](https://www.geoboundaries.org/) (release 9469f09) | [CC BY 3.0 IGO](https://creativecommons.org/licenses/by/3.0/igo/) |
| States and provinces of Malaysia, Singapore, Brunei, Timor-Leste, the Philippines and Thailand | [Natural Earth](https://www.naturalearthdata.com/) 1:10m admin-1 | Public domain |
| Land and coastlines | [Natural Earth](https://www.naturalearthdata.com/) 1:10m land | Public domain |

Map label fonts in `public/fonts/` are Noto Sans glyph ranges from
[protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets), licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/).

Modern administrative units are used only as building blocks for approximating historical
extents. Their boundaries are not evidence of historical borders.
